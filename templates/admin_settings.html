Automated Excel Email Reports

Three booking ledgers are emailed automatically each day, as soon as booking for those meals closes — 5 minutes after the relevant cutoff below (Booking Cutoff Times card). There's no separate time to set for these; they follow the cutoffs automatically.

  • Lunch report — sends at {{ report_trigger_times.lunch }} (5 min after Lunch's cutoff)
  • Snacks report — sends at {{ report_trigger_times.snacks }} (5 min after Snacks' cutoff)
  • Dinner + next-day Breakfast report — sends at {{ report_trigger_times.dinner_breakfast }} (5 min after Dinner's cutoff)

The automatic email requires the SMTP server details to be set in the app's .env file (SMTP_HOST, SMTP_USERNAME, SMTP_PASSWORD). See README.md for setup instructions and for the alternative cron / Task Scheduler method for extra reliability — changing a cutoff time changes when these reports send too, but a cron-based setup would need its own times updated to match.

Booking Cutoff Times

Once a meal's cutoff has passed, employees can no longer book (or the calendar simply won't let them pick) that meal for that date — this is enforced on save, not just shown as guidance. Admin accounts are not subject to cutoffs, so you can still adjust bookings after the deadline.
